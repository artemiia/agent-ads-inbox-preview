# ReachAgents public pages: inbox-ads preview

A preview of the two public pages, for people with an agent and for advertisers, in the
ReachAgents design and rewritten for ads an agent shows in the chat, with nothing to click.

It is a static build of the two pages only. There are no accounts, documentation or API
behind it, and the waitlist form takes no addresses here.

- People with an agent: https://artemiia.github.io/agent-ads-inbox-preview/
- Advertisers: https://artemiia.github.io/agent-ads-inbox-preview/advertisers/
